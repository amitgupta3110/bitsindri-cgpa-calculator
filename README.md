# 🎓 Students’ CGPA Calculator – BIT Sindri

A simple, accurate, and student-friendly **CGPA Calculator** designed especially for **BIT Sindri students** to evaluate their academic performance semester-wise using the official credit structure.

---

## 📖 The Story Behind This Project

At BIT Sindri, students often calculate their **CGPA manually** using spreadsheets, rough calculations, or third-party tools that do not align with the **actual credit distribution** of the institute.
This process is time-consuming, error-prone, and inconvenient—especially during result seasons.

To address this, the **Students’ CGPA Calculator** was built as a **clean, minimal, and reliable web portal** that allows students to:

* Enter their **semester-wise SGPA**
* Automatically calculate **CGPA using credit-weighted logic**
* View results instantly in a clear and structured manner

The goal is to provide **clarity, accuracy, and simplicity**—without unnecessary distractions.

## 🧮 CGPA Calculation Logic

The CGPA is calculated using the standard formula:

[
\text{CGPA} = \frac{\sum (\text{SGPA}_i \times \text{Credits}_i)}{\sum \text{Credits}_i}
]

Only semesters with valid SGPA input are considered in the calculation.
